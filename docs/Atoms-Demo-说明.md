# Atoms Demo 说明文档

## 1. 这是什么

一个可直接在浏览器打开的单文件工作台：左侧对话，右侧画布。用一句话描述应用，智能体完成「理解需求 → 设计方案 → 生成代码 → 实时预览」，产出的是真实可交互的网页，而不是静态截图。无需注册、无需后端。

- 体验文件：`Atoms智能体应用生成器-v2.html`
- 数据全部保存在当前浏览器的 localStorage，刷新不丢

## 2. 五分钟体验路径

1. 打开页面，点「模板库」选一个起点，或直接在输入框描述需求。
2. 观察右侧画布上的四步构建：解析需求、设计界面、编写代码、自检预览。
3. 在预览里真实操作：待办加一条并勾选、看板点「换一组数据」、记账记一笔、表单提交。
4. 用一句话改版：「切换成深色模式」「把主色改成薄荷绿」「标题改成……」，生成 v2，可在版本菜单回滚。
5. 刷新页面：项目、版本、以及应用内的数据都会恢复。
6. 切到「代码」看文件与行号，下载 HTML；点「部署」查看分享与上线方式。
7. 可选：点输入框左侧「本地引擎」，填入任意 OpenAI 兼容接口，即可由真实大模型生成应用。

## 3. 能力清单

- 初始化：欢迎态、六类模板的模板库（待办、看板、专注计时、记账、落地页、收集表单）
- 主流程：自然语言生成；四角色智能体状态；流式思考；构建步骤与耗时；预览/代码双视图；文件树、行号、语法高亮、复制
- 延续与延展：多轮自然语言改版；版本时间线；模板切换（如「换成数据看板」）；桌面/平板/手机画布；刷新、新窗口打开、导出 HTML、部署弹窗
- 数据持久化：工作台项目与版本、生成应用内的业务数据
- 双引擎：内置本地引擎（离线可用）+ 可选的真实模型接入（OpenAI 兼容）
- 响应式：窄屏单栏 + 底部对话/预览切换，输入框 16px 防止 iOS 聚焦缩放

## 4. 实现思路

整个 Demo 是一个自包含的 HTML 文件，无构建、无依赖、无外部资源。

**生成链路（本地引擎）**

1. 意图识别：关键词匹配到六类模板之一。
2. 生成元数据：标题、副标题、主色、深浅色、圆角、密度。
3. 模板合成：把 `index.html / styles.css / app.js` 三段模板与元数据合成。
4. 预览：拼成完整文档写入 iframe 的 `srcdoc`。
5. 改版：解析「换色 / 深浅色 / 改标题 / 圆角 / 留白 / 换模板」等指令，改写元数据后重新合成，追加新版本。

**生成链路（模型引擎）**

调用用户配置的 `/chat/completions`，用 system prompt 约束：单文件、内联资源、响应式、真实交互、`localStorage` 兜底、`<title>` 命名。返回内容解析 ```html 代码块；后续修改会把上一版完整 HTML 一起放进上下文，返回整页更新。失败时给出错误说明，并提供「改用本地引擎生成」的回退入口。

**持久化**

- 工作台：`atoms-studio-v1` 保存项目列表、每个项目的版本（含文件内容）、对话日志与当前版本。
- 生成应用：预览文档注入一个极小的 `AStore` 运行时，按 `atoms:<sessionId>:<key>` 命名空间读写；六类模板在初始化时读取、在变更时写回。
- 模型配置：`atoms-engine-v1`，仅存在本地，不上传。
- 删除项目或清空数据时，同步清理该项目的应用数据键。

**预览隔离**

iframe 使用 `sandbox="allow-scripts allow-same-origin ..."`。允许同源是为了让生成应用能使用 localStorage 完成持久化；代价是生成代码与工作台同源，生产环境应改为独立域名 + postMessage 存储代理。

## 5. 关键取舍

- **单文件而不是全栈工程**：笔试强调「可运行、可体验」。单文件零部署依赖，评审双击即可打开；代价是没有账号体系与多端同步。
- **模板 + 模型双轨**：模板保证没有 API Key 时也能完整体验全流程；模型接入证明这套交互可以平滑升级为真实生成。默认完全离线。
- **客户端持久化**：用最低成本满足「数据持久化」，以 sessionId 隔离不同应用；代价是换浏览器/设备不同步。
- **全量版本存储**：实现简单、任意回滚；代价是体积随版本增长，因此提供按项目删除与整体清空。
- **先保证主流程闭环**：没有做多人协作、评论、真实部署，把时间留给「生成 → 预览 → 改版 → 持久化」这条主链路。

## 7. 如何获得可测试链接

任选一种，都是纯静态部署：

1. Netlify Drop：打开 `app.netlify.com/drop`，把 `Atoms智能体应用生成器-v2.html` 拖进去，立即得到公网地址。
2. Vercel：新建静态项目，把文件放进去部署。
3. GitHub Pages：推到仓库，Settings → Pages 选择分支目录。
4. 本地预览：`python3 -m http.server 8080`，访问 `http://localhost:8080/Atoms智能体应用生成器-v2.html`。

注意：localStorage 按域名隔离，换域名后浏览器里的旧项目不会自动迁移。

## 8. 已知限制

- 本地引擎是规则化生成，覆盖六类常见应用；超出类型会落到最接近的模板，并明确提示。
- 模型接入受对方 CORS 策略影响；API Key 以明文存于本机 localStorage，仅适合演示。
- 部署/分享弹窗里的地址是演示占位，没有真正上传文件。
- 生成应用的数据仅存在当前浏览器；清理浏览器数据会一并丢失。
- iframe 允许同源是为了 localStorage；生产化应改为独立域 + 消息代理。

## 9. 如果继续投入的优先级

1. **P0 真实部署与分享短链**（约 4h）：对象存储 + Serverless 上传，部署弹窗换成真实地址。
2. **P1 服务端项目存储与登录**（约 6h）：项目跨设备同步、团队空间。
3. **P2 生成沙箱隔离**（约 5h）：独立域 + postMessage 存储代理，去掉同源信任。
4. **P3 版本 diff 与评论**（约 6h）：面向评审/协作的改动对比。
5. **P4 生成体验**（约 4h）：流式 token 渲染、生成中断、提示词增强与设计系统扩展。
